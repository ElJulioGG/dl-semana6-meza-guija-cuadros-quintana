# DL Semana 6

Este repositorio contiene notebooks para análisis y entrenamiento de modelos.

## Configuración del entorno

1. Ejecuta el script de setup:

```powershell
.\setupps1.ps1
```

2. Activa el entorno virtual:

```powershell
.\venv\Scripts\Activate.ps1
```

3. Abre los notebooks con Jupyter:

```powershell
python -m notebook
```
